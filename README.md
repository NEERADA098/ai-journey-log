# AI Journey Log
Daily log of technical work: data structures & algorithms, mathematics 
for machine learning, deep learning fundamentals, and project development.

## Structure
Each entry is a single markdown file under `daily-logs/`, named by date 
(`YYYY-MM-DD.md`), containing:
- What was built or proven that day
- What failed, and why
- The next day's target
- Whether work outside the current focus area was started, and why

## Purpose
A consistent, verifiable record of progress - not a summary, not a 
plan. Entries are written the same day as the work.
